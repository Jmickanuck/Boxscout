# ADR 006 — Checklist, variant and configuration identity

Accepted for Plan 005, 2026-09-14, with Justin's implementation amendments.

A release owns checklist entries and exact collectible variants. Configurations share that universe through independently sourced eligibility. Inserts/autographs are first-class entries where appropriate. A /99 variant is one collectible type; physical numbered instances arise only from later evidence work.

Base/default variant IDs deliberately equal existing entry IDs, so collection v1 flags retain their original meaning without destructive migration. Other variants use separate stable IDs. The same identifier string does not combine canonical and personal entities. Future account-backed collection entries reference variants.

Use bounded complete families and a reusable offline validator with compact repository projections. Preserve configuration uncertainty and independent image publication gates. Defer variant-detail routes, sales, values, accounts, surfaced tracking and analytics. Default gallery remains 500 Base cards; advanced criteria select exact pilot variants.
