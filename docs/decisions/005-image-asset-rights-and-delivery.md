# ADR 005 — Independent image rights and local pilot delivery

Accepted for Plan 004 on 2026-09-14.

Decision: keep exact-match review, usage rights and publication approval independent. Public output requires VERIFIED + PUBLIC_ALLOWED + APPROVED with explicit non-expiring web, transformation and repository-distribution permission. USER_SUBMITTED and OWNED_ASSET do not bypass the gate. Zero public images is acceptable.

Use a small offline local-input pipeline and public-safe metadata sidecar. Reuse the canonical image component and Next.js optimizer; bounded content-hashed WebP masters may live in public/card-images only with appropriate rights. No backend or new storage service. Pin the already-used Sharp processor for reproducibility. Builds verify generated bytes and reject unapproved public files.

Consequences: original/private inputs stay outside Git; metadata and binaries remain separate. Static delivery cannot enforce expiring licenses, which are rejected. Withdrawal requires reviewed file removal and cache/old-deployment handling. Before a future object-store migration, define separate backup, inventory and restore verification. Accounts, variants, sales, valuation and surfaced/risk calculations remain deferred.
